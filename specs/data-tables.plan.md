# Data Tables plan

Explored `https://webdriveruniversity.com/Data-Table/index.html` (title `WebDriver | Data Tables`) in Chromium at the suite's Desktop Chrome viewport, 1280×720, through the same browser-check wait the suite uses. The heading is `Data, Tables & Button States`. Nothing on the page is stored: a new visit starts from the same tables.

The page has three tables, a name form, and several static groups (breadcrumb, badges, pagination, lists). The button block is the only place a click changes what receives the event.

| Area              | What the page actually does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| First name table  | `#t01` has no caption. One row group holds the header and the rows. The rows are `John Smith 45`, `Jemma Jackson 94`, and `Michael Doe 20`.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Second name table | `#t02` uses the same headers. The rows are `Jason Jones 27`, `Sarah Jackson 56`, and `Bob Woods 80`. `Jackson` is a cell in both name tables. `Jones` is also a cell in the Table section (`Jacob Jones`).                                                                                                                                                                                                                                                                                                                                                                       |
| Table section     | The heading is `Table`. The table has no id and no accessible name. Its class is `traversal-table`. The rows are `1 Andy Otto`, `2 Jacob Jones`, and `3 Larry Scott`. The first cell of each data row is a row header.                                                                                                                                                                                                                                                                                                                                                           |
| Name form         | `#form-textfield` has no action and no method. `First name:` and `Last name:` are text nodes, not labels. The inputs have no id, no placeholder, and names `firstname` and `lastname`. The text area has no name. Its initial value is six spaces. There is no submit control inside the form. With two text fields, Enter does not submit. The typed values stay, and neither name table gains a row.                                                                                                                                                                           |
| Warning           | The button label is `Warning`. Its class is `btn btn-outline-warning disabled`. The disabled property is false, and there is no `aria-disabled`. Computed `pointer-events` is `none` and opacity is `0.65`. At 1280×720 the button is below the fold (`y` about 1726). A pointer click uses viewport coordinates, so it has to be scrolled into view. The click then hits `div.traversal-button-states`, not the button. The button is in the tab order. Space and Enter each fire a click whose target is the button. The class does not change. No control calls `myFunction`. |
| Other outlines    | `Danger`, `Info`, and `Alert` are enabled, with `pointer-events: auto`. `Info` and `Alert` share `btn-outline-info`.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Button group      | `Button-1` starts with class `active`. `Button-2`, `Button-3`, and `Button-4` do not. The parent has `data-toggle="buttons"`. The buttons are not radio labels, and none has `aria-pressed`. A click on `Button-2` leaves `active` on `Button-1`.                                                                                                                                                                                                                                                                                                                                |
| Reset             | The `Reset` control is an input in the button block, outside `#form-textfield`. A click leaves the typed first name, last name, and text area value in place.                                                                                                                                                                                                                                                                                                                                                                                                                    |

`getByRole('row', { name, exact: true })` matches one row when it is scoped to its table. The two name tables are `#t01` and `#t02` because they have no accessible name, and an id beats a content filter. The Table section has no id, so `table.traversal-table` is the locator. The name fields have no accessible name, so the locator is the `name` attribute inside `#form-textfield`. The text area is the only textarea in that form.

## Cases

The describe block is tagged `@data-tables`. Every test is `@regression`. `@smoke` is the first table and the pointer on Warning: the data, and the button state that does not match its class.

| Case                                           | Category | Priority | Tags                                  | What it checks                                                                                                                                                                                        | Why this one                                                                                                                                                                       |
| ---------------------------------------------- | -------- | -------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| the first table lists John, Jemma, and Michael | Positive | Critical | `@data-tables` `@smoke` `@regression` | The table has four rows. The three people are `John Smith 45`, `Jemma Jackson 94`, and `Michael Doe 20`. The headers are Firstname, Lastname, and Age.                                                | The primary data. The row count is the gate. Each person is its own check.                                                                                                         |
| a pointer click misses the warning button      | Negative | Critical | `@data-tables` `@smoke` `@regression` | Warning is visible and enabled, its class contains `disabled`, pointer-events is `none`, and opacity is `0.65`. The pointer hits `div.traversal-button-states`. Danger, Info, and Alert stay enabled. | The class says disabled and the property does not. A normal locator click waits until the action timeout, so the test uses a pointer click and names the element that receives it. |
| the second table lists Jason, Sarah, and Bob   | Positive | High     | `@data-tables` `@regression`          | `#t02` has `Jason Jones 27`, `Sarah Jackson 56`, and `Bob Woods 80`. It does not contain the first table's John or Jemma rows. The headers match the first table.                                     | Same headers, shared last names. A row lookup that is not scoped to one table cannot tell Sarah Jackson from Jemma Jackson.                                                        |

Enter is the key that would submit a one-field form. This form does not submit and does not grow the table.         |

## Not selected

| Category                             | Reason                                                                                                                                                                      |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enter on Warning                     | Space and Enter both synthesize a click on the focused button. The Space test is that click. A second key would repeat it.                                                  |
| A locator click on Warning           | `pointer-events: none` makes the click wait until the action timeout. The pointer test records the element that receives the click. A timeout is not an outcome.            |
| Submit, Button, Input, and Link      | Submit, Button, and Input sit outside the form and do not post it or clear it. Reset is the one whose label promises a change to the fields. Link only adds `#` to the URL. |
| Breadcrumb                           | Contact Us has `aria-current="page"`. Home and About Us are links to `#`. Nothing in the tables or the button block changes. Lower than the controls that look live.        |
| Badges                               | Today's Deals is 5 and All Products is 20. The numbers are static text.                                                                                                     |
| Pagination                           | Previous, 1 through 5, and Next are links to `#`. None has a current page. Clicking 2 adds a hash and does not mark a page. The table does not page.                        |
| The text area's six spaces           | The field looks empty and its value is six spaces. The reset test fills it and checks that value. A separate test would only lock the initial spaces.                       |
| Drinks, food, and jobs lists         | Static lists. Coffee through Sugar have ids. They are not a table outcome or a button state.                                                                                |
| The marked sentence and the citation | Static text. No control changes them.                                                                                                                                       |
| `myFunction`                         | The page defines an alert, `I am an alert box!`, and no control calls it.                                                                                                   |
| Keyboard on the button group         | The group click is a pointer click. The buttons have no key handler of their own. Button activation is the Warning case, where the pointer and the key disagree.            |
| Mobile widths                        | The suite runs Desktop Chrome only. Covering the breakpoints would mean a config change.                                                                                    |
