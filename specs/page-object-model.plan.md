# Page Object Model plan

Explored the homepage card `PAGE OBJECT MODEL` (`Page-Object-Model/index.html`, `target="_blank"`) and both documents it opens, in Chromium at the suite's Desktop Chrome viewport, 1280×720, through the existing bot-wall path.

The home document title is `WebDriver | Page Object Model`. The product document title is `WebDriver (New Approach To Learning)`. There are no fields. The in-page menu is Home `index.html`, Our Products `products.html`, and Contact Us `../Contact-Us/contactus.html`. The brand link is site chrome.

| Surface        | What the page actually does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Welcome dialog | `Find Out More!` (`#button-find-out-more`) opens `#myModal`. The heading is `Welcome to webdriveruniversity.com`. The body is `Welcome to webdriveruniversity.com we sell a wide range of electrical goods such as laptops, game consoles, cameras...`. Close hides it. The dialog's own `Find Out More` button has no link; it only dismisses, and the URL stays `/Page-Object-Model/index.html`. Enter and Space both open it, because the control is a button. Escape leaves it open. × and the backdrop hide it, the same as Close. |
| Carousel       | `#carousel-example-generic` starts on `../img/amp.svg`, then `../img/boombox.svg`, then `../img/nintendo.svg`, then wraps. The next and previous controls have no accessible name. The next control advances one slide and does not change the URL. The timer advances a slide about every 5 seconds. Hovering the carousel for several seconds did not keep the current slide still. The first two images share `id="slide-image-1"`.                                                                                                  |
| Our Products   | The menu loads `/Page-Object-Model/products.html` and shows Special Offers, Cameras, New Laptops, Used Laptops, Game Consoles, Components, Desktop Systems, and Audio. Home on that document returns to `/Page-Object-Model/index.html`. The products document does not mark Our Products active.                                                                                                                                                                                                                                       |
| Product dialog | Every tile is a link with `href="#"` inside a `data-toggle="modal"` block pointed at one `#myModal`. The dialog copy is already in the document: heading `SPECIAL OFFER! - GET 30% OFF YOUR FIRST ORDER AT WEBDRIVERUNIVERSITY.COM`, terms that require orders over £50, and the code `NEWCUSTOMER773322`. Cameras shows that same dialog. The click adds `#` and stays on `products.html`. Proceed has no checkout; it only dismisses. Close, ×, and the backdrop hide it. Escape leaves it open.                                      |
| Contact Us     | The menu loads `/Contact-Us/contactus.html` with the title `WebDriver \| Contact Us` and the heading `CONTACT US`. The form itself belongs to Contact Us.                                                                                                                                                                                                                                                                                                                                                                               |

The page title is in the head, and jQuery and Bootstrap are the last scripts in the body. A dialog click waits until `jQuery.fn.modal` is registered. Until then the button is in the document and the click does not open the dialog.

Locators, in the project order: the menu, the product names, `Find Out More!`, and the dialog buttons are roles with those names. The dialog heading is a heading. The dialog has no accessible name and stays in the document while it is hidden, so `#myModal` is the locator, and the heading and the coupon are read from inside it. The carousel controls and the current slide have no accessible name. `data-slide="next"` is the next control. The current slide is the `.item.active` image inside `#carousel-example-generic`. The duplicate slide id is not a locator.

`toHaveText` on the offer copy would pass on the first poll while the dialog is still hidden, because that copy is already in the document. The checks wait until the heading or the coupon is visible, and until it is hidden again after a dismiss. Those are hidden for the whole fade.

## Cases

Tags: `@page-object-model` on the describe block, `@regression` on every test. `@smoke` on the welcome dialog and the coupon, so those tests carry both.

| --------------------------------------------- | -------- | -------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| find out more opens the welcome dialog        | Positive | Critical | `@smoke` `@regression` | `Find Out More!` shows the welcome heading and the goods sentence. Close hides the heading.                                                                       | The only action on the home document. It is the smallest check that the dialog opened, so it is one of the two `@smoke` tests.                                                |

It is the other `@smoke` test.                                                                              |

The coupon test also walks this link; this one stops on the list, so a broken tile cannot hide a broken menu.                               |

The form belongs to `tests/contact-us.spec.ts`.                                                                       |

## Not selected

| Category                            | Reason                                                                                                                                                                                         |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The other six product tiles         | New Laptops, Used Laptops, Game Consoles, Components, Desktop Systems, and Audio open the same `#myModal` and the same offer copy as Cameras. One tile that is not Special Offers covers that. |
| Previous control and the dots       | They call the same slide handler as next. The next test covers a forward move, including the wrap from the last image.                                                                         |
| A fixed second image                | The timer can move the first slide before the test reads it. The check is the following image, not `boombox.svg` in particular.                                                                |
| Hover to pause the carousel         | The pointer sat on the carousel while a later sample showed the next image. The test stops the timer through the carousel plugin and checks that the plugin reports paused.                    |
| Escape                              | Escape leaves the dialog open. Button Clicks already treats that as Bootstrap, not a separate outcome.                                                                                         |
| × and the backdrop                  | They hide the dialog, the same as Close. Close is the dismiss in the welcome test.                                                                                                             |
| Opening the welcome dialog again    | Close and the dialog's `Find Out More` both hide it. The Enter test opens it on its own. A second open is the same open path.                                                                  |
| Empty, invalid, or whitespace input | No fields and no form on these two documents.                                                                                                                                                  |
| Disabled controls                   | None of the controls are disabled.                                                                                                                                                             |
| The products menu item is active    | The products document does not add `active` to Our Products. The URL is the location.                                                                                                          |
| The contact form                    | Submit, reset, and validation are `tests/contact-us.spec.ts`.                                                                                                                                  |
| The brand link                      | Site chrome. It loads the site home. The in-page menu is the navigation this page owns.                                                                                                        |
| The framed copy of this home        | `tests/iframe.spec.ts` covers the frame boundary. This spec is the two documents themselves.                                                                                                   |
| Mobile widths                       | The suite runs Desktop Chrome only. Covering the collapsed navbar would mean a config change.                                                                                                  |
