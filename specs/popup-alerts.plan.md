# Popup & Alerts plan

Explored `https://webdriveruniversity.com/Popup-Alerts/index.html` (title `WebDriver | Popups & Alerts`) in Chromium at the suite's Desktop Chrome viewport, 1280×720, through the existing bot-wall path. The heading is `Annoying Popup & Alerts!`. There are no fields.

| Control                | What the page actually does                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JavaScript Alert       | `#button1` is a span. `onclick` calls `myFunction()`, which calls `alert("I am an alert box!")`. Nothing on the page changes after OK.                                                                                                                                                                                                                                                                                                   |
| JavaScript Confirm Box | `#button4` is a span. `onclick` calls `confirmAlert()`, which calls `confirm("Press a button!")`. OK sets `#confirm-alert-text` to `You pressed OK!` and `#10b981` (`rgb(16, 185, 129)`). Cancel sets `You pressed Cancel!` and `#9a9a9a` (`rgb(154, 154, 154)`). The paragraph starts empty. A later choice replaces the text.                                                                                                          |
| Modal Popup            | `#button2` is a span with `data-toggle="modal"` and `data-target="#myModal"`. It opens the Bootstrap dialog `#myModal`. The title is `It’s that Easy!! Well I think it is.....` (the apostrophe is U+2019). The body is the `WebElement.click()` paragraph below. Close and × use `data-dismiss="modal"`. A click on the overlay, outside the dialog, also hides it. Escape leaves it open. The modal is in the page and hidden on load. |
| Ajax Loader            | The control is a link, `a[href="../Ajax-Loader/index.html"]`, around `#button3`. A click opens `/Ajax-Loader/index.html`. It does not open a dialog on this page.                                                                                                                                                                                                                                                                        |

The four visible labels are all `CLICK ME!`. The alert, modal, and confirm controls are spans, so they have no button role. Each has a unique id. The Ajax Loader control is the only link with that name. `#confirm-alert-text` has no accessible name until a choice is written, so the id is the locator. `#myModal` has `role="dialog"` and no accessible name, and it stays in the page while hidden, so the id is the locator.

`#button1`, `#button2`, and `#button4` have `tabIndex` `-1`. Tab from the document reaches the navbar brand and then the Ajax Loader link, and nothing else. Enter and Space on the three spans do not open a dialog. Focusing `#button1` from the test runner leaves focus on `body`.

Dialog methods register `page.waitForEvent('dialog')` before the click that opens the dialog. The alert is gone if nothing is listening.

## Cases

Tags: `@popup-alerts` on the describe block, `@regression` on every test. `@smoke` only on the one successful outcome for each popup that lives on this page, so those tests carry both.

| Case                                               | Category | Priority | Tags                                   | What it checks                                                                                                                                                   | Why this one                                                                                                                            |
| -------------------------------------------------- | -------- | -------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| the javascript alert shows its message             | Positive | Critical | `@popup-alerts` `@smoke` `@regression` | The confirm result starts empty. The dialog message is `I am an alert box!`. After OK the result is still empty and the URL is still `/Popup-Alerts/index.html`. | The alert's only outcome is that message. The empty result is the page text: this control writes nothing.                               |
| accepting the confirm shows You pressed OK         | Positive | Critical | `@popup-alerts` `@smoke` `@regression` | The result starts empty. The dialog message is `Press a button!`. OK sets `You pressed OK!` and `rgb(16, 185, 129)`.                                             | The success branch. The color is the visible result of that branch, not only the string.                                                |
| dismissing the confirm shows You pressed Cancel    | Negative | High     | `@popup-alerts` `@regression`          | The result starts empty. The dialog message is `Press a button!`. Cancel sets `You pressed Cancel!` and `rgb(154, 154, 154)`.                                    | The other branch. The OK test would still pass if Cancel wrote the same text.                                                           |

The outcome is the navigation. The loader page has its own spec, so this test stops at the URL.               |

## Not selected

| Category                                     | Reason                                                                                                                                                                     |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Prompt dialog                                | N/A. The page never calls `prompt`. There is no input dialog to accept or dismiss.                                                                                         |
| Empty, invalid, or whitespace input          | N/A. There are no fields and no form. Nothing to reject.                                                                                                                   |
| Disabled or read-only controls               | N/A. None of the four controls are disabled.                                                                                                                               |
| A separate negative for the JavaScript alert | N/A. An alert has only OK. Dismiss closes it the same way, and the page still writes nothing. That unchanged page is the positive test, not a second outcome.              |
| Keyboard activation of the three popup spans | N/A. They are not in the tab order, and they have no key listeners. Enter and Space do not open a dialog. A keyboard failure would be a new requirement, not a broken one. |
| Enter on the Ajax Loader link                | N/A as its own case. The control is a native link. Enter follows the href, which is the browser, not a page handler. The click test covers that URL.                       |
| Escape to close the modal                    | Checked on the live page. Escape leaves the modal open. Not a test: the page does not offer that dismiss path.                                                             |
| Ajax Loader page contents                    | The click only leaves this page. The spinner, the delayed control, and that modal are `tests/ajax-loader.spec.ts`.                                                         |
| Dismiss paths that repeat Close              | Close is the success test. × and the overlay are the other two real dismissals. A second Close click is not a new outcome.                                                 |
| Navbar brand link                            | Site chrome, not a popup outcome.                                                                                                                                          |
| Mobile widths                                | The suite runs Desktop Chrome only. Covering the breakpoints would mean a config change.                                                                                   |
